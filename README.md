# Generador de Horario Académico

## 🚀 Cómo usar

1. **Seleccionar bloques:** Haz clic en cualquier celda vacía de la cuadrícula para seleccionarla. 
2. **Unir horas (Bloques continuos):** Si tienes una clase que dura varias horas, mantén presionada la tecla `Ctrl` (o `Cmd` en Mac) y haz clic en las celdas consecutivas para seleccionarlas juntas.
3. **Añadir la materia:** Haz clic en el botón **"Añadir Materia"**, escribe el nombre de la asignatura en la ventana emergente y presiona Guardar. Las celdas se combinarán automáticamente.
4. **Personalizar el color:** Haz clic en el ícono de la paleta de colores en la parte inferior para cambiar el tono neón de toda la interfaz.
5. **Exportar:** Una vez que tu horario esté listo, haz clic en el ícono de imagen para descargar automáticamente una captura en formato `.png`.
